# AI Job Market Analysis - Excel
Interactive Excel dashboard analyzing AI job market trends including job roles, salary distribution, experience levels, employment types, and industry demand using pivot tables, charts, and slicers.

📊 Project Overview :

  This project analyzes the AI job market using an interactive Excel dashboard.
  The analysis explores job roles, salary distribution, employment types, industries, and experience levels to understand current AI job market trends.

📁 Dataset :

  Source: Kaggle AI Job Market Dataset
  Records: ~2000 rows
  Features: Job Role, Salary, Experience Level, Industry, Employment Type, Skills
  🛠 Tools Used
  Microsoft Excel
  Pivot Tables
  Pivot Charts
  Slicers
  Excel Formulas

📌 Dashboard Features :

  Employment Type Distribution
  Job Roles Requiring Excel
  Salary Category Distribution
  Average Salary by Experience Level
  Job Openings by Role
  Salary Categories by Industry
  Job Distribution Across Industries

🔍 Key Insights :

  NLP Engineer has the highest average salary among AI roles.
  Data Analyst has the highest number of job openings.
  Automotive industry shows strong demand for AI professionals.
  Senior-level positions receive significantly higher salaries compared to entry and mid-level roles.
